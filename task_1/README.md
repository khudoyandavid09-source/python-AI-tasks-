### Description

This is a basic Python script that prints the result of a simple arithmetic operation.

### Explanation

The script uses the built-in `print()` function to output the result of the expression `1+1`. This is a fundamental concept in Python programming and is often used as a starting point for beginners.

### Run Instructions

To run this script, follow these steps:

1. Save the script as a file named `1.py` (or any other name you prefer).
2. Open a terminal or command prompt.
3. Navigate to the directory where you saved the script.
4. Type `python 1.py` (or the name of your script) and press Enter.
5. The script will run and print the result to the console.
