**Simple Arithmetic Operation**
-----------------------------

This Python script performs a basic arithmetic operation, adding two numbers together.

**Description**
---------------

The script uses the built-in `print()` function to output the result of the arithmetic operation `1 + 2`.

**Explanation**
--------------

* The script uses the `print()` function to output the result of the expression `1 + 2`.
* The expression `1 + 2` is evaluated and the result is passed to the `print()` function.
* The `print()` function outputs the result to the console.

**Run Instructions**
--------------------

1. Save the script as `2.py`.
2. Open a terminal or command prompt.
3. Navigate to the directory where the script is saved.
4. Run the script using the command `python 2.py`.
5. The result of the arithmetic operation will be output to the console.

**Example Output**
-----------------

```
3
```
